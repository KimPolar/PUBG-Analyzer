# PUBG map assets

The map images in this directory are WebP conversions of the `Low_Res` map assets from the official [`pubg/api-assets`](https://github.com/pubg/api-assets) repository.

- Source revision: `32b13b51128b8d8909ae5e77f3b833e01230b24d`
- Source directory: `Assets/Maps`
- Conversion: 819×819 source dimensions retained, WebP quality 84

The original assets remain subject to the PUBG API [Terms of Use](https://developer.pubg.com/terms) and PUBG [Player-created Content](https://pubg.com/en/clause/ugc_policy) policy described by the source repository.
